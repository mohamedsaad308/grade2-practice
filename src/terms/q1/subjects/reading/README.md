# Q1 Reading Subject Guide

This folder contains the Q1 Reading subject module under `src/terms/q1/subjects/reading/`.

## How to add a new Reading topic:
Create a topic content file in `src/terms/q1/subjects/reading/content/` and loader in `src/terms/q1/subjects/reading/topics/` adhering to the standard schema, and import it into `src/terms/q1/subjects/reading/index.js`.
